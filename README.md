-- legenda --

autonoame atunci cand coechipierul are autonom si el:
- protagonist = cel care trage primul / se spawneaza in fata la hive ul cu nectar
- deuteragonist = opusul protagonistului / asteapta sa dea protagonistul tip

autonoame atunci cand coechipierul nu are autonom:
- thespian = se spawneaza ca protagonistul dar face tot
- aeschylus = se spawneaza ca deuteragonistul dar face tot
